# Engine API (read this instead of src/)

Load order in index.html: `math.js`, `scene.js`, `gl.js`, `shaders.js`, `assets/textures*.js`,
`assets/models/*.js`, `world.js`, then `main.js`. All globals, no modules (file:// must work).

## world.js — `WORLD` (the file you edit for scenes and movement)
- `WORLD.build(world, models)`: once. `models[name]` = root SceneNode of each model in `SCENE_CONFIG.models`;
  position them (`root.pivot`, `root.axis`/`root.angle`) and `world.add(...)` them.
- `WORLD.update(dt, t, input)`: every frame in live mode. `input.keys['KeyW']` etc. are true while held.
- Current controls: W/S drive, A/D turn, Q/E slew the upper body. The machine faces +X at heading 0;
  forward = `[cos(a), 0, -sin(a)]`.
- Excavator nodes: `excavator` (model root, drive + heading) → `undercarriage` → `upper` (slew, axis +Y).
- Tests load `world.js` in Node (`tests/excavator.test.js` shows how) — keep it free of DOM/GL calls.

## math.js — `Vec3`, `Mat4` (column-major Float32Array(16))
- `Vec3.add/sub/scale/dot/cross/length/normalize`
- `Mat4.identity()`, `Mat4.mul(A, B)` (applies B first), `Mat4.translation(x,y,z)`, `Mat4.scaling(x,y,z)`
- `Mat4.rotation(axis, rad)`, `rotationX/Y/Z(rad)`, `Mat4.transpose(m)`, `Mat4.invert(m)` (null if singular)
- `Mat4.normalMatrix(model)` → 3x3 for normals, `Mat4.perspective(fovY, aspect, near, far)`, `Mat4.lookAt(eye, target, up)`
- `Mat4.transformPoint(m, [x,y,z])`

## scene.js — `SceneNode(name)`
- Fields: `pivot` (in parent frame), `axis`, `angle`, `limits`, `offset` (extra Mat4), `mesh`, `color` [r,g,b], `texture` (name)
- `local = T(pivot) * R(axis, angle) * offset`; `world = parent.world * local`
- `add(child)`, `setAngle(rad)` (clamped to limits), `updateWorld(parentWorld|null)`, `traverse(fn)`, `find(name)`, `worldOrigin()`

## gl.js — `GLX`
- `GLX.init(gl)` once after the context (enables 32-bit indices for imported meshes)
- `GLX.createProgram(gl, vs, fs)` → program with `.attribs` / `.uniforms` maps; throws with the compile log
- `GLX.loadModel(gl, window.MODELS[name])` → root `SceneNode` with one child node per exported part, hierarchy already wired
- `GLX.getTexture(gl, name)` → WebGL texture from `window.TEXTURES[name]` (white until loaded)
- `GLX.drawMesh(gl, prog, mesh)`, `GLX.hexToRgb('#rrggbb')`

## shaders.js — `SHADERS.litVS`, `SHADERS.litFS`
Blinn-Phong: hemisphere ambient (`uSkyColor`/`uGroundColor`) + one directional sun (`uSunDir` toward the sun,
`uSunColor`), specular via `uShininess`/`uSpecular`, albedo = `uBaseColor` × texture when `uUseTexture` = 1.

## main.js
Reads `window.SCENE_CONFIG` (in index.html): `models`, `camera`, `testCamera`, `test` thresholds, `light`.
URL modes: none = interactive orbit (drag / wheel), `?test` = self-check line, `?shot` = still for screenshots.

## Model files (`assets/models/<name>.js`, generated by tools/export.py)
`window.MODELS[name] = {name, parts:[{name, parent, pivot, axis, limits, color, texture, vertexCount, indexCount,
position, normal, uv, index, [indexType "u16"|"u32"], [doubleSided], [source "imported"]}], data: base64}` —
offsets are byte offsets into the decoded buffer; GL frame (Y-up). Missing `indexType` means u16.

## Builders (`builders/<name>.py`)
`build()` returns part dicts in CadQuery's Z-up frame: `name, parent, pivot, axis, limits, shape, color, texture, uv_scale`.
Each shape is modelled with its joint pivot at the origin. Optional `EXPECT = {part: {"bbox_size": [x,y,z] (GL frame), "tol": m}}`.
